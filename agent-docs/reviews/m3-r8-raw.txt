1. **P2 — Failure writers bypass egress accounting.** [crates/gdl/src/dist/hop.rs:626](/home/ryan/repos/dynamo-gdl/crates/gdl/src/dist/hop.rs:626). Forward-only runs reserve no egress permit, but `fail()` attaches and sends unconditionally. With multiple instances, a forward handoff can reach an instance whose quota is occupied by another request’s backward run; downstream refusal then creates an additional velo sender, channel, and heartbeat task outside the quota. **Change wanted:** reuse an existing permit or acquire one under the request/setup bounds before attaching, retaining it through failure delivery. Add a regression with saturated egress and a refused forward handoff.

2. **P2 — The admission regression does not establish its precondition.** [crates/gdl/tests/faults.rs:1243](/home/ryan/repos/dynamo-gdl/crates/gdl/tests/faults.rs:1243). Sampling admission after 800 ms does not prove failure delivery has started. If forwarding/admission takes longer, the pre-fix implementation still holds its share and passes; if the sampler runs after delivery finishes, correct code fails. **Change wanted:** add an observable failure-delivery barrier, await entry, assert admission while delivery is blocked, then release it. Verify that moving `drop(share)` before delivery deterministically fails.

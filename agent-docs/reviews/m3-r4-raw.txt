1. **P2 — Local backward-run provisioning bypasses `setup_timeout`.** [crates/gdl/src/dist/hop.rs:275](/home/ryan/repos/dynamo-gdl/crates/gdl/src/dist/hop.rs:275). When a backward run revisits the outer segment, it calls `open_run` directly. Its egress wait is bounded only by `admission_wait` and the request deadline. With exhausted local egress, a 100 ms setup timeout and 3 s admission wait, provisioning can retain previously opened runs for 3 s. **Change wanted:** apply the setup timeout to the entire local opening, matching remote provisioning. Add a regression with saturated local egress and `admission_wait > setup_timeout`.

2. **P2 — Cleanup assertions cannot detect leaked egress permits.** [crates/gdl/tests/common/mod.rs:882](/home/ryan/repos/dynamo-gdl/crates/gdl/tests/common/mod.rs:882). `settles()` succeeds when admission, attempts, and anchors reach zero, even if egress permits remain held. A fault-path regression that releases those resources but leaks its permit therefore passes the shared cleanup check while eventually exhausting capacity. **Change wanted:** include `egress_in_use() > 0` in the predicate and verify that deliberately retaining a permit makes the check fail.
